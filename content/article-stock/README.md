# 記事ストック

ここは、からだ成分ラボの未公開記事を保管する領域です。

- `content/articles.json`へ移すまではサイトに掲載しない。
- 一記事一トピックを守る。
- 公開前に情報源の現行表示、本文、図解、モバイル表示を再確認する。
- ストック段階では、読者の疑問、読後の理解、原稿、図解仕様、次回へ送る内容を記録する。

## 公開へ進めるときの順番

1. 読者の疑問と一文の結論が一つになっているか確認する。
2. 現在の公式一次資料を確認し、参照日を更新する。
3. `content/article-template.json`へ移し、`karada-article-v1`で本文と主画像を仕上げる。
4. 編集チェック、画像の目視、モバイル表示、自動検査を完了してからPRにする。
