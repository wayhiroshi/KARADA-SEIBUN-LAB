# からだ成分ラボ

「まんがでわかる、栄養と健康成分」をテーマにした静的漫画解説サイトです。

## 第1話

- タイトル：ランチ15分前、からだの中では？
- 補足：糖の流れを整える、体内物流チームの物語
- 公開形態：セリフなし画像＋各コマ直下のセリフ

## ローカル生成

```bash
npm run build
npm run check
```

生成先は `dist/` です。画像原画や制作資料は公開リポジトリには含めません。

## Cloudflare Pages

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`
