# SNS投稿テンプレート

テンプレートは公開前に `post-review-checklist.md` で審査する。価格・商品情報は投稿当日に公式ページとショッピングモールで確認する。

## 教育カルーセル

販売リンク、招待コード、製品CTAを置かない一般情報用。

### スライド

1. 読者の疑問を一文で示す
2. 用語Aの定義
3. 用語Bとの違い
4. 広告・表示で混同しやすい点
5. 自分で確認する3項目
6. 情報源と「保存して後で確認」

### 本文

```text
［疑問・テーマ］

結論からいうと、
・［要点1］
・［要点2］
・［要点3］

成分の一般的な役割と、特定の食品を摂ったときの効果は別の問いです。
今回は［一次資料］をもとに、表示を読むための基礎だけを整理しました。

主な情報源:
［公的機関・論文URL］

この投稿は一般的な情報提供で、診断・治療・予防や特定製品の効果を保証するものではありません。
```

## 30〜45秒短尺

本人の声を使う教育シリーズ名は「耳でほどく、からだ成分」とする。初月はAI音声を使用せず、植井寛本人の自然な声と全文字幕で制作する。

```text
0〜3秒: 「からだ成分ラボの植井寛です。今日は［用語］を40秒でほどきます」
4〜12秒: ［用語Aの短い定義］
13〜21秒: ［用語Bの短い定義］
22〜31秒: 「商品表示では［確認点］を見ます」
32〜40秒: 「一般的な仕組みと製品効果は分けて読みましょう」
41〜45秒: 「あとで確認できるよう保存」
```

研究を扱う短尺では、研究対象、人数、期間、研究段階のいずれかを省略して強い結論だけを出さない。

### 音声の共通ルール

- 売り込み口調ではなく、表示を一緒に読む案内人として話す
- 一文を短くし、専門語の直後に生活者向けの言い換えを置く
- BGMより声を優先し、全文字幕を付ける
- 効能を暗示する抑揚、効果音、ビフォーアフター演出を使わない
- 元音声は公開ファイルと分けて非公開保管する
- 定型の締めは「効きそう、ではなく、何が書かれているかから考える。からだ成分ラボでした。」

## 販売PR投稿

本プロジェクトで書面確認済みとしている媒体・配置条件を満たし、招待コード発行後に使用する。回答範囲外の媒体・形式では使用しない。

```text
【PR／広告】

フォーデイズ「核酸ドリンク ナチュラル DNコラーゲン」の公式ショッピングモールをご案内します。

［公開日に確認した商品名・名称・内容量・通常価格］
［公式表示の範囲内の原材料・お召し上がり方］
［公式注意事項］

私自身が利用して感じる［味・手間・続け方に関する主観］。
これは個人の感想で、健康効果を保証するものではありません。

公式ショッピングモールでは、会員登録なしに通常価格で購入できます。
販売・配送はフォーデイズ社が行います。

私はフォーデイズ会員です。この招待コード経由で購入があった場合、紹介者である私に販売ボーナス等が反映されます。

［加工していない招待URL］

※健康づくりはバランスのよい食生活が基本です。
※通院中・服薬中、妊娠・授乳中、アレルギー等に不安がある場合は、原材料と公式注意事項を確認し、医師・薬剤師等へ相談してください。
```

### 画像

- 「PR／広告」と公式ロゴの表示方法はFordaysの書面回答どおりにする
- 公式製品画像は独立したスライドで無加工使用する
- 文字、装飾、ロゴを製品画像へ重ねない
- プラットフォーム側の自動トリミングを避ける

## 利用記録

販売CTAを含める場合はPR投稿として扱う。

```text
記録日:
開栓日:
量:
割り方:
味の主観:
準備・片付けにかかった手間:
冷蔵庫での保管:
費用について感じたこと:

書かない項目:
体調改善、病気、検査値、若返り、身体機能の変化を製品効果として結びつける表現
```
