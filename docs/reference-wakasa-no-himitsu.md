# 参考サイト研究: わかさの秘密

確認日: 2026-08-13
参考サイト: [わかさの秘密](https://himitsu.wakasa.jp/)

## 参考にする目的

「からだ成分ラボ」を、初めて健康成分を調べる人にも入りやすく、次に読む記事を迷わず選べるサイトへ育てるため、情報の探し方、記事の見せ方、視覚表現を研究する。

文章や図版を模倣するのではなく、読者が情報へたどり着きやすくなる設計原則を抽出して使う。

## 参考になる点

### 1. 読者の出発点に合わせた入口

トップページには、次のような複数の探し方が明確に用意されている。

- 成分名から探す
- 悩みから探す
- 食べ物から探す
- キーワードを入力して探す

成分名を既に知っている人だけでなく、「食べ物から知りたい」「自分の関心から探したい」という人にも入口がある。五十音やアルファベットから成分を探せる索引もあり、記事が増えた後の回遊設計として参考になる。

### 2. トップページを一覧ではなく案内板にしている

新着記事を並べるだけではなく、「いま注目されている成分」やランキングなど、次の一記事を選ぶ理由が示されている。サイトへ初めて来た人が、どこを押せばよいか迷いにくい。

### 3. 親しみやすい視覚表現

- 食べ物や身体を題材にした大きなイラスト
- 淡い背景と十分な余白
- 角を丸めた白いカード
- 入口ごとに役割を分けた色
- 虫眼鏡を中心にした「調べる場所」と分かるシンボル

難しく見えやすい健康成分を、図鑑や読み物のように近づきやすく見せている。からだ成分ラボでも、単なる飾りではなく、内容や入口の違いを伝えるイラストと色を使う。

### 4. 記事を読む順序が見える

代表的な成分記事では、冒頭に短い説明と要点があり、目次、詳しい説明、食品や摂り方、研究情報、参考文献へ進む構成になっている。更新日、関連記事、参考文献も示され、記事の位置づけが分かりやすい。

## からだ成分ラボへの取り入れ方

### すぐに記事制作へ取り入れる

各記事は、次の順序を基本にする。

1. 日常語による一つの疑問
2. 一文で分かる答え
3. 答えを見える形にした主図解
4. 理由を短く説明する本文
5. 確認に使った情報源
6. 自然に続く「次の疑問」一つ

これは既存の「一記事一トピック」のルールを変えるものではない。長い総合解説へ寄せず、一つずつ理解できる連載として実現する。

### 記事が増えた段階で取り入れる

記事が20〜30本ほど蓄積したら、トップページの入口を次の三つに整理することを検討する。

- **成分名から探す**: DNA、RNA、ヌクレオチドなど
- **身近なものから探す**: 粉ミルク、母乳、食品、商品表示など
- **疑問から探す**: 「DNAはどこにある？」「RNAとmRNAは違うの？」など

あわせて、サイト内検索と「初めて読む3本」を設ける。病気や症状を入口にして特定成分や商品へ直結させず、読者が実際に抱く疑問を入口にする。

### 実績データがたまってから取り入れる

GA4とSearch Consoleで十分な閲覧データが得られたら、「よく読まれている記事」を掲載する。人気順を編集上の想像で作らず、集計期間を明示し、実データを使う。

## そのまま取り入れない点

- 一つの記事に効果、食品、摂取量、研究など複数の疑問をまとめる構成
- 症状や病名から特定成分・商品へ短絡的につなぐ導線
- 個別研究や一般的な成分情報を、製品の効果のように見せる表現
- 強い改善・予防表現や、根拠の範囲を超えた断定
- 見出し文字を画像だけで表現する方法
- 実データに基づかない人気ランキング
- 参考サイトの文章、図版、配色、キャラクター、ブランド表現の模倣

からだ成分ラボでは、科学的な正確さ、自然な日本語、一記事一トピック、見て分かる図解、筆者と一緒に学ぶ語り口を優先する。

## 今後の記事で確認すること

- この記事は「成分名」「身近なもの」「日常の疑問」のどの入口に属するか。
- タイトルと主図解だけで、答える疑問が分かるか。
- 読み終えた人が、次に知りたい一つの疑問へ進めるか。
- 関連記事を増やすために、別トピックを本文へ詰め込んでいないか。
