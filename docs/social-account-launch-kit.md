## ブランドの声

### 声の役割

植井寛の声は、強く売り込むためではなく、難しい表示を隣で一緒に読む「安心できる案内人」として使う。

- 落ち着いていて聞き取りやすい
- 一文を短くし、専門語の後に必ず言い換えを置く
- 相手を怖がらせず、判断を急がせない
- 「効く・治る」ではなく「ここを確認します」と話す
- 声だけで結論を断定せず、画面上に主要情報源を表示する

### 音声シリーズ名

`耳でほどく、からだ成分`

### 定型オープニング

```text
こんにちは、からだ成分ラボの植井寛です。
今日も、成分名に振り回されないために、一緒に表示を読んでいきましょう。
```

30〜45秒の短尺では、次の短縮版を使う。

```text
からだ成分ラボの植井寛です。
今日は「［用語］」を、40秒でほどきます。
```

### 定型クロージング

```text
効きそう、ではなく、何が書かれているかから考える。
からだ成分ラボでした。
```

### 収録基準

- 本人の自然な声を基本とし、初月はAI音声を使用しない
- 1本の収録は完成尺より少し長い60秒以内
- 話速を急がず、専門語の前後に短い間を置く
- BGMはなくてもよい。使用する場合は声を妨げない小音量にする
- 全文字幕を付け、音声なしでも内容が分かるようにする
- 言い間違いだけを編集し、過度に切り刻んだ話し方にしない
- 元音声は公開素材と分けて非公開保管し、第三者へ渡さない

## 固定投稿3本

### 固定1: このアカウントについて

- 形式: 6枚カルーセル
- 表紙: `50代から、成分名に振り回されない。`
- 内容:
  1. からだ成分ラボの目的
  2. 核酸を看板テーマにする理由
  3. 漫画で全体像をつかむ
  4. 本人の声で難しい言葉をほどく
  5. 一般情報とPR投稿を分ける
  6. 「保存して、必要なときに読み返してください」

### 固定2: 植井寛について

- 形式: 著者画像と本人ナレーション
- 主文:

```text
私は医師や研究者としてではなく、健康情報を調べる一人の生活者として発信します。
研究や広告をそのまま信じるのではなく、対象、人数、期間、表示を一緒に確認する案内人でありたいと考えています。
```

- Fordays製品の販売PRを行う関係を明確にするため、説明欄へ次を置く:

```text
私はフォーデイズ会員です。販売投稿を行う場合は【PR／広告】と利害関係を明示し、一般情報とは分けて掲載します。
```

### 固定3: 情報の読み方

- 形式: チェックリスト
- 見出し: `健康情報を見るときの5つの確認`
- 確認項目:
  1. 誰について調べた研究か
  2. 何人を、どれくらいの期間調べたか
  3. 成分の研究か、販売製品そのものの研究か
  4. できたことと、まだ分からないことは何か
  5. 発信者に販売上の利害関係があるか

## 初月の販売PR

### PR1: 製品の基本表示

教育投稿から日を分け、研究や一般的な核酸の説明を購入理由として接続しない。

```text
【PR／広告】

フォーデイズ「核酸ドリンク ナチュラル DNコラーゲン」の
公式ショッピングモールをご案内します。

名称：清涼飲料水
内容量：720ml
通常価格：12,840円（税込）

購入者はフォーデイズ会員への登録をせず、通常価格で購入できます。
販売・配送はフォーデイズ株式会社が行い、私は紹介者です。

私はフォーデイズ会員です。
この招待URL経由で購入された場合、私に販売ボーナス等が反映されます。

［発行された無加工の招待URL］

※価格、在庫、原材料、注意事項は公開日に公式画面で再確認します。
※本投稿は製品による病気の治療、予防、身体機能の改善を示すものではありません。
```

画像は、PR表示・公式ロゴ・購入条件を示す案内スライドと、無加工の公式製品画像スライドを、書面回答で承認された順序・配置にする。製品画像へ文字やロゴを重ねない。

### PR2: 購入手順

```text
【PR／広告】

公式フォーデイズショッピングモールでの購入手順です。

1. 発行された招待URLから公式ショッピングモールを開く
2. 招待コードを削除せず、製品と最新価格を確認する
3. 会員登録ではなく、通信販売として購入手続きをする
4. フォーデイズ株式会社から製品が販売・配送される

私はフォーデイズ会員で、この招待URLから購入があった場合、
紹介者である私に販売ボーナス等が反映されます。

［発行された無加工の招待URL］

送料、支払方法、返品条件は、購入時の公式画面でご確認ください。
```

QRを使用する場合も、発行された画像を加工せずそのまま掲載する。

## 初月の短尺台本

### W1: 核酸を40秒でほどく

```text
からだ成分ラボの植井寛です。
今日は「核酸」を、40秒でほどきます。

核酸は、一つの商品名ではありません。
DNAとRNAをまとめて呼ぶ言葉です。

まず覚えるのは、
核酸という大きな括りの中に、DNAとRNAがあること。

成分の一般的な説明と、
その商品を摂ったときの効果は、分けて読みましょう。

効きそう、ではなく、何が書かれているかから考える。
からだ成分ラボでした。
```

### W2: DNAとRNAを一言ずつ

```text
DNAとRNA。似ていますが、同じものではありません。

DNAは、遺伝情報を長く保つ役割。
RNAは、その情報を使う過程で、さまざまな働きを担います。

ここで大切なのは、
体の中での役割と、食品として摂ったときの話を混ぜないこと。

商品表示を見るときも、まずは何が、どれだけ書かれているかを確認します。
```

### W3: 三つの言葉の関係

```text
核酸、DNAとRNA、ヌクレオチド。
三つの言葉を、箱と部品で考えてみます。

核酸は大きな分類。
その中にDNAとRNAがあります。
そして、それらを形づくる基本単位がヌクレオチドです。

難しい成分名も、分類と部品に分けると読みやすくなります。
```

### W4: 成分名より先に見る3項目

```text
知らない成分名を見つけたとき、
すぐに「効くか」を検索していませんか。

その前に見るのは三つです。
何が入っているか。
どれだけ入っているか。
一日にどれくらい摂る表示か。

成分名の印象より、まず表示を同じ条件で読む。
これが、からだ成分ラボの基本です。
```

## 初月に見る数字

初月は注文数だけで成功・失敗を判断しない。次を記録する。

- カルーセルのリーチと保存数
- 短尺の再生数、最後まで見られた割合
- プロフィール訪問数
- コメント・質問数
- 声が聞きやすいか、速いか、長いかという反応
- 招待URLのSNS側クリック数
- Fordays側で翌日以降に確認できる集計注文数

毎週、保存率または質問数が最も高かった一テーマだけを翌週の短尺・FAQへ再利用する。初月終了時に、声あり動画と字幕中心動画の反応を比べ、2か月目の収録量を決める。

- [ ] 3媒体で表示名、画像、説明が一致している
- [ ] 著者画像が小さい円形表示でも本人と分かる
- [ ] 教育サイトと無加工招待URL以外の中継・短縮リンクを置いていない
- [ ] Fordays会員であることと、販売PR投稿の方針を固定投稿で開示した
- [ ] 書面回答の媒体・配置・ロゴ条件を制作画面へ反映した
- [ ] 販売PRは一般情報・研究解説と別投稿になっている
- [ ] 音声は本人が公開を確認した完成版だけを使用する
- [ ] 字幕だけでも意味が通る
- [ ] 病気、改善、若返り、効能保証を含まない
- [ ] 情報源を投稿本文または最終スライドに示す
