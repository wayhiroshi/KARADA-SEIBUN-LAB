# からだ成分ラボ 正式ブランドロゴ

最終更新: 2026-07-27

## 採用

2026-07-27に、実験器具と顕微鏡を組み合わせたシンボルと
`Karada Seibun Lab`の文字を用いたロゴを正式採用した。

学ぶ、観察する、成分を読み解くという「からだ成分ラボ」の姿勢を、
健康食品そのものではなくラボの道具で表現する。

## 原本

- 編集用原本: `logo.ai`
- 配布用原本: `logo.svg`
- 購入素材原本: `AdobeStock_315685537.ai`

原本は直接加工せず、用途別ファイルは`npm run prepare:brand`で生成する。

## 用途別ファイル

| ファイル | 用途 |
|---|---|
| `public/assets/brand/karada-seibun-lab-logo.svg` | Web・印刷用フルロゴ |
| `public/assets/brand/karada-seibun-lab-logo-1200.png` | SVGを使えない場所のフルロゴ |
| `public/assets/brand/karada-seibun-lab-mark.svg` | サイトヘッダー・favicon・小型表示 |
| `public/assets/brand/karada-seibun-lab-avatar-1024.png` | Instagram・YouTube・Facebookのプロフィール画像 |

プロフィール画像にはフルロゴを縮小せず、シンボル専用画像を使う。
表示名は画像内へ入れず、媒体のプロフィール名で表示する。

## 基本色

- ラボブルー: `#1497D4`
- ディープネイビー: `#001B41`
- 背景: 白 `#FFFFFF`

ロゴの色、比率、パーツ配置は変更しない。影、縁取り、グラデーション、
文字追加、回転は行わない。背景写真上へ置く場合は、視認性を保つため
白い独立領域を設ける。

## 人物画像との使い分け

- ブランドを認識してもらう場所: ロゴ
- 植井寛の人柄や声を伝える場所: 著者画像
- 製品販売投稿: 本ブランドロゴとFordays公式ショッピングモールロゴを混同しない

Fordays公式ロゴ、公式製品画像、招待URL・QRにはFordaysの利用条件を適用する。
本書の加工ルールは「からだ成分ラボ」独自ロゴに関するものであり、
Fordays公式素材の加工許可を意味しない。
