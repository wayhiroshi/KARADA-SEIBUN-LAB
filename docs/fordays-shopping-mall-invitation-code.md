# フォーデイズショッピングモール招待コードの仕組みと運用メモ

## この文書の目的

健康・栄養を扱う漫画や記事の中でフォーデイズ製品に触れ、一般の方を公式フォーデイズショッピングモールへ案内する構想について、2026年6月・7月に提供された公式資料4点から読み取れる仕組み、運用条件、商品情報、実装上の注意点を共有する。

この文書は提供PDFの要約であり、フォーデイズの最新規約確認や法的助言の代わりではない。実際の公開前には、会員サイトにある最新版のガイド、会員規約、公式素材、商品表示を再確認する。

## プロジェクトの採用方針（2026年7月27日）

販売導線は、公式資料で利用例として認められているSNS投稿で運用する。

| 場所 | 役割 |
|---|---|
| からだ成分ラボ | 健康・栄養の漫画と一般情報を提供する。招待用URL・QRは掲載しない |
| SNS | フォーデイズ製品を広告投稿として紹介し、招待用URL・QRから公式ショッピングモールへ案内する |
| 公式ショッピングモール | 一般ユーザーから通信販売として注文を受ける |

漫画サイトを販売ページや招待コードの中継ページとして使用しない。漫画サイトから招待コード付きSNS投稿へ計画的に誘導する導線も、許容されることをフォーデイズへ確認するまでは設置しない。

## 先に結論

- 一般ユーザーはフォーデイズ会員にならず、公式ショッピングモールで「通信販売」として商品を購入できる。
- 会員が発行した個人用URLまたはQRコードから購入手続きへ進むと、紹介者IDが自動反映される。
- 紹介者には、ショッピングモール価格と会員価格の差額に応じた販売ボーナスと、p.v.に応じたボーナスが反映される。
- 購入者は紹介者のダウンライン会員になるわけではない。ただし、紹介実績のp.v.はビジネスプランに応じて最大12段上位まで反映されるため、紹介側の報酬処理は既存の会員制度と接続している。
- したがって、利用体験は「招待コード型アフィリエイト」に近いが、誰でも参加できる一般的なアフィリエイトプログラムではない。招待コードはフォーデイズ会員IDに紐づく公式機能である。
- **現行資料では、個人で作成したホームページ内に招待用URL・QRを掲載することが禁止されている。現在の漫画サイトから公式ショッピングモールへ直接リンクする実装は、そのまま進められない。**
- SNSでの利用は案内されているが、「PR」または「広告」の表示と公式ロゴの併記が必須である。
- サイトからSNSを経由させるなどの迂回導線が許容されるかは、提供資料だけでは判断できない。設計前にフォーデイズへ対象ドメインと具体的な導線を示し、確認を得る必要がある。

## 仕組み

```text
フォーデイズ会員
  │
  ├─ 会員サイトから会員ID別の招待用URL・QRを発行
  │
  └─ 許可された媒体で、ルールに従って案内
          │
          ▼
一般ユーザー
  │
  ├─ 招待用URL・QRから公式ショッピングモールへアクセス
  ├─ 紹介者IDが自動反映された状態で注文
  └─ 会員登録ではなく「通信販売」として購入
          │
          ▼
フォーデイズ側の処理
  │
  ├─ 紹介者へ販売ボーナスを反映
  ├─ 紹介者へp.v.に応じたボーナスを反映
  ├─ p.v.はプランに応じて最大12段上位まで反映
  └─ 注文日の翌日にダウンライン実績へ反映
```

### 紹介者に反映されるもの

1. 公式フォーデイズショッピングモール価格と会員価格の差額に応じた販売ボーナス
2. p.v.（ポイントバリュー）に応じたボーナス

ガイドでは、購入月度内で計算し当月末に支払うと説明されている。

### 購入者に関する制約

- 購入者は通常の会員登録とは異なり、通信販売の顧客として扱われる。
- 購入者の氏名などは紹介者へ開示されない。
- 招待コードを削除して注文すると「ご紹介なし」の注文になり、後から紹介実績へ変更できない。
- したがって、紹介者側で「誰が何を買ったか」を照合する運用はできない。

## 招待コードの発行

### 対象

- ガイド上の対象は全会員。ただしK会員は除外される。
- 2026年6月18日から、従来のDR保有者限定ではなく全会員向けに拡大された。
- K会員へ変更した場合はサービスが停止する。コースへ復帰した場合は、以前の招待コードを再取得・再設定せず、そのまま利用できる。

### 発行場所

会員サイトの次の経路から取得する。

```text
通販（ショッピングモール）
  → ショッピングモール招待コード発行申請
```

### 発行手数料

- 1IDあたり1,100円（税込）
- 月額ではなく、発行時に1回だけ発生する
- 複数IDを申請すると、IDごとに手数料が発生する
- 毎月18日から翌月17日を1月度とし、発行当月度のマスタIDのボーナスから相殺される
- 当月に相殺できない場合は、ボーナスが発生した月度に相殺される
- ボーナス明細では「ショッピングモール招待コード発行サービス手数料」として、相殺払戻（その他）明細に記載される

### 発行後の性質

- 1つの会員IDにつき、1種類のURL・QRが発行される。
- 同じURL・QRをX、Instagram、Facebookなど複数のSNSで共通利用できる。
- URL末尾とQR中央に会員ID末尾3桁が表示され、複数IDを識別できる。
- 色、デザイン、URL、QRを変更・加工してはならない。
- 間違ったIDで案内しても、注文受付後に紹介者IDを変更できない。
- 発行後の停止操作はできない。使わない場合は掲載・配布を控える。
- URL・QRが分からなくなった場合は再発行せず、会員サイトの「発行済」ボタンから確認する。

## 媒体ごとの利用条件

### SNS

SNSへの掲載は公式資料で利用例として認められている。次の2点が必須である。

1. 投稿本文またはハッシュタグに「PR」または「広告」のいずれかを表示する
2. 投稿画像または投稿内に公式フォーデイズショッピングモールの公式ロゴを併記する

招待コードだけを置くのではなく、広告関係を明確にした投稿として扱う。

このプロジェクトでは、各販売投稿を次の構成にする。

1. 投稿の冒頭または見落とされない位置に「PR」または「広告」を表示する
2. 会員サイトから取得した公式ショッピングモールのロゴを掲載する
3. 製品画像を使う場合は、会員サイトから取得した無加工の公式画像を使う
4. 製品説明は最新の公式情報で確認できる事実の範囲に限定する
5. 発行された招待用URL・QRを変更せずに掲載する
6. 一般ユーザーが会員登録ではなく通信販売として購入できることを、必要に応じて分かりやすく案内する

投稿文、画像、招待用URL・QRは公開前に一式で確認する。健康漫画の内容を、そのまま個別製品の効果・効能の根拠として使用しない。

### 本人が運営するサロン・店舗

申請者本人が運営するサロンや店舗では、次の方法が例示されている。

- 受付カウンターへ公式ロゴ付きのQRポップを設置する
- 公式ロゴ、QR、URLを掲載したショップカードを置き、来店者に自由に持ち帰ってもらう

一方、グループメンバーなど第三者が運営する店舗・施設への設置や利用はできない。

### 名刺

- 連鎖販売取引で使用するフォーデイズの名刺には、ショッピングモールのロゴ、招待用URL、QRを載せられない。
- ショッピングモール用の名刺は別に作成する。
- 公式テンプレートは提供されていない。

### ホームページ

ガイドには次の制限が明記されている。

> 個人で作成されたホームページ内には、ショッピングモールの二次元コードやURLを掲載することはできません。

このため、現在の「からだ成分ラボ」の記事や漫画から招待用URLへ直接リンクする案は、提供資料の範囲では実装不可と判断する。

別ページ、短縮URL、リダイレクト、SNSプロフィールなどを使って実質的に同じ導線を作ることが許されるとは資料に書かれていない。禁止事項の迂回と受け取られる可能性があるため、フォーデイズの確認なしに採用しない。

## 素材と表現のルール

### 公式ロゴ

- 招待用URL・QRを印刷物やデジタル媒体へ掲載するときは、公式ショッピングモールの公式ロゴを併記する。
- 公式ロゴは会員サイトの「ショッピングモール招待コード発行申請」ページから取得する。
- 独自に描き直したロゴや、資料から切り抜いたロゴで代用しない。

### 製品画像

- 会員サイトからダウンロードした製品画像を使う。
- レイアウトに応じたサイズ変更（拡大・縮小）だけが認められている。
- トリミング、文字・イラスト・装飾の追加、色調補正、合成などの加工を行わず、そのまま使用する。
- 製品の形状、色、デザインなどが実物と異なる表現になる使い方をしない。
- ダウンロードした画像を第三者へ提供・配布しない。
- 景品表示法、薬機法、会員規約、各種ガイドラインを遵守する。
- 不適切な利用は、サービス停止などの措置につながる可能性がある。
- 提供カタログの画像をWeb掲載用素材として転用してよいとは明記されていない。カタログPDFから画像を抜き出して使わない。

### ローカル保管

会員サイトから取得した画像、製品資料、抽出テキスト、索引は、次のローカル専用ディレクトリへ保管する。

```text
private-assets/fordays-official-materials/
```

このディレクトリは `.gitignore` でリポジトリから除外する。素材や抽出内容を公開リポジトリ、公開サイト、第三者がアクセスできるストレージへ保存しない。

### 公式素材の取得状況（2026年7月27日）

会員サイトの製品資料・画像ダウンロード画面に表示された14カテゴリ、208項目を確認した。

| 取得結果 | 件数 |
|---|---:|
| 利用可能な製品資料（PDF） | 122 |
| 利用可能な製品画像（PNG） | 85 |
| 配布元リンク切れ（404） | 1 |
| 合計 | 208 |

リンク切れは「フォーデイズ ポンポン ヘアパウダー」の資料1件である。リンクが返した404ページを証拠として非公開保管庫へ保存した。利用可能な公式素材は207件で、原本のSHA-256、PDFページ数、画像寸法、カテゴリ、抽出状態を台帳化している。

PDFは製品説明を後から横断検索できるよう、PDFごとのテキストと全資料をまとめた検索用本文を作成した。埋め込みテキストを抽出できた資料は117件、画像だけのPDFに部分OCRを付けた資料は5件である。OCR結果は誤認識の可能性があるため、SNS投稿文へ使う際は必ず原本PDFと最新の公式商品表示を確認する。

非公開保管庫内の主な参照先:

```text
private-assets/fordays-official-materials/
├── originals/images/
├── originals/documents/
├── originals/errors/
└── indexes/
    ├── product-materials.md
    ├── files.csv
    ├── files.json
    ├── searchable-corpus.txt
    └── text/
```

### 製品説明

次の表現は禁止されている。

- 事実に反する説明
- 誇張した説明
- 根拠のない効果・効能の案内
- 「病気が治る」「病気を予防する」「免疫力が上がる」など、資料の禁止例に相当する表現

健康漫画の一般的な解説と、個別商品の説明を混同しない。漫画の内容をそのまま製品効果の根拠に見せる構成も避ける。

## サービスが停止される条件

次のいずれかに該当すると、招待コードサービスは自動停止される。

1. 申請したIDがK会員へ変更、または退会となった場合
2. ガイドに記載された禁止行為が判明した場合
3. 会員規約違反により、資格停止や活動制限などの処分を受けた場合

## 現在の漫画サイト構想への適用

### そのまま進められる部分

- 健康・栄養に関する一般向け漫画や記事を公開する
- 商品販売を目的としない独立した情報発信として、読者に役立つ内容を作る
- 製品について触れる場合も、事実に反する表現、誇張、根拠のない効果・効能を避ける
- 購入者が会員登録ではなく通信販売で購入できる仕組みを、内部設計上理解しておく

### 現時点で進めてはいけない部分

- 漫画サイトに個人用招待URLを直接掲載する
- 漫画サイトに個人用QRを掲載する
- ボタン、画像リンク、短縮URL、リダイレクトなど、見せ方だけ変えて同じ誘導を行う
- カタログPDFから製品写真や公式ロゴを切り出してサイトへ掲載する
- 漫画の健康解説を特定製品の効果保証として見せる

### 公開実装前に必要な確認

フォーデイズへ、少なくとも次を具体的に確認する。

1. 対象サイトのURLと運営者
2. 健康漫画・記事の内容
3. 製品に触れる箇所の表示例
4. 招待コードを置きたい位置と媒体
5. サイトからSNSなど別媒体へ移動させる場合の導線
6. 使用予定の公式ロゴ、製品画像、商品説明
7. 「PR」「広告」表示をどこに出すか

確認結果は口頭だけでなく、後から参照できる形で保管する。

## 計測・運用設計への影響

- 採用方針では、漫画サイトに商品CTAや招待用リンクを設置しない。サイト側では記事閲覧や読了など、健康情報コンテンツ自体の利用状況を計測する。
- 販売導線の表示回数、反応、リンククリックはSNS側の分析機能で確認する。
- 購入者の個人名は紹介者へ開示されないため、サイト訪問者と購入者を個人単位で結びつけない。
- フォーデイズ側で確認できる紹介実績、p.v.、販売ボーナスは集計値として扱う。
- URLから招待コードが外れた購入は後から訂正できない。
- 複数SNSで同じ招待URLを使うため、招待コードだけでは媒体別成果を区別できない。媒体別計測が必要な場合も、URLを加工せず、許可された範囲の自サイト外クリック計測やSNS側の分析機能を使う。
- 価格、商品仕様、在庫、招待コード運用規則は変わり得る。公開時に公式ショッピングモールと会員サイトで再確認する。

## 提供カタログの位置づけ

2つの製品カタログは、商品情報の本文と中面が同じで、表紙レイアウトが異なる版である。どちらもPDF上はA4横・4ページで、商品カテゴリは次の3系統に整理されている。

1. Supplement
2. Skincare & makeup
3. Hair & Body

カタログは一部商品の紹介であり、全商品一覧ではない。価格はすべて税込で、製品詳細は公式ショッピングモールで確認するよう案内されている。

## 運用チェックリスト

### コンテンツ制作前

- [ ] 健康解説と製品説明の境界を決める
- [ ] 製品に触れる必然性があり、記事単体でも読者価値がある
- [ ] 医療的な診断、治療、予防、効果保証の表現がない
- [ ] 最新の公式商品説明と価格を確認する

### 素材使用前

- [ ] 公式ロゴを会員サイトから取得する
- [ ] 製品画像を会員サイトから取得する
- [ ] 製品画像は拡大・縮小以外の加工をしていない
- [ ] トリミング、文字・装飾の追加、色調補正、合成をしていない
- [ ] ロゴ、URL、QRを加工していない
- [ ] 画像を第三者へ提供・配布していない
- [ ] カタログPDFから画像を抜き出していない

### 導線実装前

- [ ] このサイトへの招待URL・QR掲載可否について、フォーデイズの確認がある
- [ ] 掲載媒体が申請者本人の運営媒体である
- [ ] 第三者の店舗、施設、アカウントへ貸与していない
- [ ] SNS投稿には「PR」または「広告」がある
- [ ] SNS投稿には公式ロゴがある
- [ ] 使用する会員IDを取り違えていない

### 公開後

- [ ] 実際の公開画面でPR表示、公式ロゴ、URL・QRを確認する
- [ ] スマートフォン表示でも表示が欠けていない
- [ ] 招待コードが削除されず、公式ショッピングモールへ遷移する
- [ ] 商品説明、価格、規則の更新有無を定期確認する
