# からだ成分ラボ 漫画・音声によるInstagram成長運用

最終更新: 2026-08-16

## 結論

難しい知識を説明するアカウントではなく、読者が以前から気になっていた疑問を、漫画と本人の声で短時間に解決するアカウントとして運用する。

一つの親テーマを、次の順で展開する。

1. **漫画**で「自分にもある疑問」として興味を持ってもらう
2. **植井寛の声のリール**で非フォロワーへ届ける
3. **カルーセル**で図解を保存できる形にする
4. **Web記事**で根拠と詳しい説明を読む
5. **ストーリーズ**で質問を集め、次の親テーマへつなげる

販売開始までは、理解、共感、信頼、質問の蓄積を優先し、教育投稿へ販売要素を混ぜない。

## アカウントの見え方

### 目指す印象

- 難しい話を、身近な疑問から考えられる
- 何でも知っている先生ではなく、一緒に学んでいる人がいる
- 図を見るだけでも一つ分かる
- 植井寛の穏やかな声で安心して聞ける
- 続きを読んだり保存したりしたくなる

### 避ける印象

- 教科書の要約
- 専門用語を知っている人だけが入れる講義
- 一枚目から説明文が並ぶ資料
- 図解の形をした文字中心のスライド
- 健康不安を強く刺激する投稿

## 一つの親テーマから作るもの

| 形式 | 役割 | 標準仕様 |
|---|---|---|
| 漫画 | 共感と興味の入口 | 3〜5コマ、登場人物の疑問から開始 |
| リール | 新しい人への発見 | 15〜30秒、本人音声、最初の2秒で疑問 |
| カルーセル | 保存と理解 | 3〜5枚、一枚一メッセージ、4:5 |
| Web記事 | 深掘りと検索 | 一記事一トピック、主図解、一次情報源 |
| ストーリーズ | 会話と次回テーマ | 二択、質問箱、理解度確認のいずれか一つ |

媒体ごとに別テーマを作らない。漫画、音声、図解、記事は、同じ一文の結論を違う深さで伝える。

## 漫画の基本構成

### 3コマ型

1. **疑問**: 植井寛または読者役が、日常語で疑問を言う
2. **見える化**: 身近なたとえ、拡大、入れ子、比較で関係を見せる
3. **発見**: 一文の結論と「今日はここまで」

### 5コマ型

1. 思い込み
2. 違和感または質問
3. 調べる場面
4. たとえによる発見
5. 一文の結論

### 演出ルール

- 一コマの吹き出しは原則二つまで
- 一つの吹き出しを短くし、説明文を詰め込まない
- 人物は感情と発見を伝えるために使い、図解の代わりに長く話させない
- 男女を出す場合も、不必要な身体接触や過度な親密さを入れない
- 筆者として植井寛を描く場合は、登録済みの本人ビジュアルを基準にする
- 製品画像は漫画へ合成せず、販売投稿の公式素材として別管理する

## 声のリールの基本構成

### 15〜30秒テンプレート

```text
0〜2秒  「〇〇って、△△だと思っていませんか？」
3〜8秒  「私もそう思っていました」
9〜20秒 身近なたとえと図解を一つ
21〜27秒 一文の結論
最後     「今日はここまで。図で見たい方は次の投稿へ」
```

音声は早口にせず、字幕は音声の全文ではなく要点だけにする。動画を見なくても字幕で、音声を聞かなくても画面で結論が分かる状態にする。

## 表紙・冒頭の言葉

専門用語そのものではなく、読者の頭に浮かぶ疑問を置く。

| 説明的な入口 | 採用する入口 |
|---|---|
| RNAとmRNAの包含関係 | RNAとmRNA、別物なの？ |
| DNAの細胞内局在 | DNAって体のどこにある？ |
| 必須栄養素の定義 | 「必須」って、そんなに大事？ |
| ヌクレオチドの乳児栄養 | 粉ミルクにヌクレオチド？なぜ？ |

## 30日間の成長運用

現在の制作・公開済み投稿と不足素材は[`social-publication-status.md`](social-publication-status.md)で管理する。

### 毎週

- 漫画カルーセル: 1本
- 漫画を動かした本人音声リール: 2本
  - 1本目は中心疑問
  - 2本目は入口表現を変えた短縮版
- Web記事: 1本
- ストーリーズ: 2〜3回
- 関連する公開投稿への内容あるコメント: 5〜10件
- Facebookへ漫画または記事を1回転載
- YouTube Shortsへリールを1回再利用

Trial Reelsがアカウントで利用できる場合は、入口表現を試す用途に使う。利用可否はInstagramアプリで都度確認し、機能の有無を成果の前提にしない。

### 初月に販売要素は入れない

核酸、DNA、RNA、細胞、栄養に関する疑問を通して、アカウントの役割と植井寛の人柄を理解してもらう。商品名、招待コード、購入訴求は入れない。

## 次の4週間の親テーマ

| 週 | 中心疑問 | 漫画のたとえ | リール冒頭 |
|---|---|---|---|
| 1 | mRNAは何をするの？ | 本と持ち運ぶメモ | 「DNAの本は、どうやって使う？」 |
| 2 | DNAはどうやって小さな核に入るの？ | 長い糸を整理して収納 | 「2メートルのDNAが、どう入る？」 |
| 3 | ヌクレオチドは何でできているの？ | 三つの部品 | 「核酸の材料を、さらに分けると？」 |
| 4 | 健康情報の研究は、誰を調べたの？ | 条件カードを並べる | 「その結果、自分にも当てはまる？」 |

第2週以降の科学的な結論は、公開前に一次資料で確定する。疑問案の段階にある説明を、そのまま事実として漫画化しない。

## 増加を判断する数字

フォロワー数だけで判断しない。Instagram Insightsで取得できる範囲から、次の順で見る。

1. 非フォロワーへのリーチ
2. リールの冒頭離脱と平均視聴時間
3. 保存とシェア
4. プロフィール閲覧
5. プロフィール閲覧からのフォロー
6. Webサイトへのプロフィールリンク遷移

毎週、最も反応が高かった入口表現を一つだけ翌週へ再利用する。投稿量を一度に増やさず、漫画の導入、音声の冒頭、表紙の疑問を順番に改善する。

## 毎週の提案

Codexの定期提案は毎週月曜日9時に行う。直近の公開内容と取得できる反応を確認し、次の一組を提案する。

- 漫画3〜5コマ
- 本人音声リール15〜30秒
- 保存用カルーセル3〜5枚
- Web記事の中心疑問と一文の結論
- Facebook・YouTube Shortsへの再利用
- 前週から一つだけ改善する点

提案と制作準備までを定期運用とし、SNS投稿、Web公開、広告出稿は自動実行しない。
