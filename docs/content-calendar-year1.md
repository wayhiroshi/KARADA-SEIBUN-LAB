# 初年度コンテンツカレンダー

最終更新: 2026-08-16

毎週一つの親テーマを調査し、3〜5コマ漫画、15〜30秒本人音声リール2本、保存用カルーセル、Facebook・YouTube転載、Web記事へ再利用する。販売PRは別原稿・別審査で月2本作成する。初月は販売投稿を出さず、疑問、理解、共感、質問の蓄積を優先する。

Instagramでの入口は専門用語ではなく、読者の日常語による疑問にする。具体的な展開方法と最初の4週間は [`instagram-comic-growth-loop.md`](instagram-comic-growth-loop.md) を正本とする。

未公開の制作待ち原稿は [`content/article-stock/`](../content/article-stock/) に保管する。ストックから公開へ移す場合も、一記事一トピックの編集ルールに従い、情報源と公式表示を公開日に再確認する。

開設時の固定投稿と本人音声台本は[`social-account-launch-kit.md`](social-account-launch-kit.md)を使用する。現在の制作・公開状況は[`social-publication-status.md`](social-publication-status.md)を正本とする。初期の教育運用には販売投稿を混ぜず、販売PRは商品情報・公式素材・表示条件を公開日に再確認した後の別工程とする。

月1件は「読んでほどく」として、読書中の書籍から一つの論点を選ぶ。書評だけで終わらせず、書籍の主張、示された出典、確認できる一般情報、限界、次に調べることを一つの親テーマにまとめる。発達障害に関する書名や著者の主張を、栄養やFordays製品による改善効果として転用しない。
