# からだ成分ラボ：核酸啓蒙・SNS販売 年間運用計画

最終更新: 2026-08-16

## 目的

「からだ成分ラボ by 植井寛」を、年齢や性別を限定せず、健康情報や成分表示を自分で確かめたい人のための情報源として育てる。核酸を看板テーマとし、漫画と声で理解を助け、必要な人を公式ショッピングモールの会員登録不要購入へつなげる。50代は現在の発信テーマの一つとして扱い、属性だけで関心や理解度を決めつけない。

販売主体はフォーデイズ社であり、植井寛は紹介者である。次の事実は内部で正確に管理し、購入導線を含む販売投稿で必要な範囲だけ表示する。

- 公式ショッピングモールでは、一般ユーザーが会員登録なしに通常価格で購入できる
- 販売・配送はフォーデイズ社が行い、会員は製品を直接販売しない
- 植井寛はフォーデイズ会員であり、招待コード経由の購入により販売ボーナス等が反映される

## ブランド

- 名称: からだ成分ラボ by 植井寛
- コピー: 50代から、成分名に振り回されない。漫画でほどく、からだ成分ラボ
- 役割: 成分表示と研究を、健康情報を調べる人の目線で読み解く案内人
- 初年度前半の販売軸: 核酸ドリンク ナチュラル DNコラーゲン
- 成功条件: 年間120注文、規約・法令上の事故ゼロ、週7時間以内

本プロジェクトでは、個人サイト、Instagram、Facebook、YouTubeにおける招待URL・QR、公式ロゴ、無加工製品画像の利用について、Fordaysの書面確認を取得済みという前提で運用する。実際の公開形式は回答書に記載された媒体・配置条件を優先し、回答範囲を超える新媒体・新形式は追加確認する。

## 週5〜7時間の制作工程

一つの親テーマから、漫画、本人音声リール、保存用カルーセル、Web記事、ストーリーズへ展開する。詳しい正本は `docs/instagram-comic-growth-loop.md` とする。

| 作業 | 週の目安 |
|---|---:|
| 一次資料・公式表示の確認 | 75分 |
| 3〜5コマ漫画と保存用図解 | 100分 |
| 15〜30秒本人音声リール2本の台本・収録・編集 | 90分 |
| Facebook・YouTubeへの再利用、予約投稿 | 40分 |
| ストーリーズ、関連投稿への内容あるコメント、質問整理 | 35分 |
| 数値確認と翌週テーマ選定 | 30分 |
| 表示・価格・リンクの公開前確認 | 30分 |

Web記事は親テーマごとに一記事一トピックで公開し、月1回、反応のよかったテーマを統合記事または既存記事の更新へ反映する。公開量を増やすより、非フォロワーへのリーチ、視聴維持、保存、シェア、プロフィール遷移、質問が高い入口を更新・再利用する。

### Instagramの成長原則

- 難しいテーマを避けるのではなく、入口を日常の疑問へ変える
- 漫画で共感と発見、本人音声リールで新規発見、カルーセルで保存、Webで深掘りを担当する
- 「私はこう勘違いしていた」という学び途中の実感を、2〜3本に1本入れる
- 専門用語、商品名、研究名を一枚目の主役にしない
- 最初の100人までは、Facebook再利用、関連投稿への内容あるコメント、質問への記事回答で初期接点を作る
- 毎週月曜日に、次の漫画・音声・カルーセル・Web記事を一組で提案する

## コンテンツ配分

- 核酸の基礎: 40%
- 成分リテラシー: 25%
- 研究の読み方: 15%
- 製品FAQ・購入案内: 15%
- 植井寛の利用記録: 5%

利用記録は味、費用、手間、飲み方、続けやすさに限定する。体調改善、病気の予防・治療、若返り、身体機能の改善を示す体験談にはしない。

### 公開情報と内部運用の境界

コンプライアンス遵守は制作・運営側の内部工程とし、ブランドの売り文句、固定投稿、プロフィール、教育記事へ持ち込まない。読者には疑問への答え、理解しやすさ、選ぶための具体的な材料を届ける。

法令、プラットフォーム規約、フォーデイズ公式ルールによって表示が必要な場合だけ、対象の販売投稿へ簡潔に掲示する。販売投稿の「PR／広告」、紹介報酬との関係、価格・購入条件など必要な表示は省略しない。審査手順、書面許可、禁止表現、画像利用条件、媒体ごとの運用判断は公開前チェックリストと非公開運用領域で管理する。

## SEO方針

### 検索テーマ

1. 核酸とは、DNA・RNA・ヌクレオチドの違い
2. 核酸を含む食品と、食品・サプリの違い
3. 核酸サプリの原材料、表示量、1日当たり費用の読み方
4. 核酸、NMN/NAD、コラーゲン、核酸医薬の違い
5. 研究の対象、期間、主要評価項目、限界、利益相反
6. 健康食品の表示と選び方

「おすすめランキング」ではなく、読者自身が原材料、含有表示、1日当たり価格、販売者、根拠を比べられる判断基準を提供する。

### 公開品質

- 全記事で「一記事一トピック」を守り、読者へ渡す新しい理解を一段分に絞る
- すべての記事に中心的な関係を一目で伝える主図解を設け、文字だけを詰め込まない
- 図解、余白、カード、色分けなどを目的に応じて使い、不要な装飾を省く
- 詳細な制作基準は `docs/article-editorial-rules.md` を正本とする
- 記事ごとに著者、公開日、更新日、主要情報源を表示
- 著者ページと、記事制作・訂正・プライバシーをまとめた運営ページを用意
- 広告関係は販売導線がある投稿にだけ明瞭に表示
- canonical、sitemap、robots、Article/Breadcrumb構造化データを生成
- Search Console登録は公開後に行う
- GA4は測定IDを取得し、プライバシー方針へ追記してから有効化する

M1は招待コード発行、承認条件に沿った最初の販売投稿が完了した月とする。

Natural DNコラーゲン1本につき、通常価格12,840円と会員価格9,950円の差額による販売ボーナスは2,890円。現在のタイトルなしでは、直接招待を1次ライン、標準換算5,330p.v.、1次ライン率15%として注文単位で四捨五入するとp.v.分は800円となり、1件あたりの標準報酬試算は3,690円となる。

年間120件では、計画売上1,540,800円、販売ボーナス346,800円、p.v.分96,000円、合計442,800円。招待コード発行手数料1,100円を1ID分差し引いた参考額は441,700円である。

この計算は`/Users/yoshiaki/Documents/Fordays報酬計算`を正本とし、このプロジェクト内へp.v.計算ロジックを複製しない。再計算は次のコマンドで行う。

```sh
npm run forecast:rewards -- \
  --course A \
  --title NONE \
  --orders 0,1,2,4,6,8,10,12,14,17,21,25
```

コースAは表示上の入力であり、タイトルなしの1次ライン率15%はA・B・F・G・Iで共通。本人の当月定期購入、返品・取消、インボイス経過措置、源泉徴収、振込手数料、その他相殺は含めないため、正式額は公式明細を優先する。

## 広告費

最初の90日間は広告費ゼロ。その後も次を満たすまで広告を開始しない。

1. Fordaysから有料SNS広告の書面許可を得ている
2. 正しいPR・ロゴ・画像配置を確認できている
3. 媒体別に誤認のない計測方法がある
4. 返品等反映後の平均報酬を確認できている

試験する場合は月3万円を上限とし、許容CPAは「返品等反映後の平均報酬／注文の50%以下」とする。

## 進捗判断

- M3: 累計3件未満でも投稿量を増やさず、対象者、入口テーマ、プロフィール、CTAを診断する
- M6: 累計10件未満なら年間予測を作り直し、核酸需要、信頼性、購入導線を分けて改善する
- M9: 累計57件の50%未満なら広告を使わず、上位5コンテンツと購入前FAQへ集中する
- M12: 120件、違反ゼロ、週7時間以内を確認する
- 第二製品は、Natural DNコラーゲンが月15件以上を3か月継続した場合だけ追加する

## 実績管理

公開リポジトリには空のテンプレートだけを置く。実績値はGit管理外の `private-ops/monthly-scorecard.csv` へ記録する。

購入者の氏名などは取得・照合せず、SNS側の集計クリックとFordays側の集計注文数を月単位で比較する。招待URLへ解析パラメータを付けたり、計測用リダイレクトを挟んだりしない。
