## 1. 判定記号

- **R（Reuse）**：既存画像の人物・構図を使用し、Illustratorで新しい台詞を組版する。
- **M（Modify）**：既存画像を使用するが、看板、埋め込み文字、巨大な空欄などの画像修正が必要。
- **N（New）**：複数の旧コマを統合するか、新しい意味関係を描くため再生成する。
- **X（Exclude）**：旧版から外し、新版では掲載しない。

## 2. 公開画像の固定方針

1. Web公開版では、絵とHTML台詞を分け、読みやすさと読み上げ対応を優先する。
2. SNS用など画像単体で配布する版を作る場合は、通常台詞を`GenEiAntiqueNv6-M.ttf`、幅が狭い場合だけ`GenEiAntiquePv6-M.ttf`で別画像へ組版する。
3. 空の吹き出しや用途不明の字幕枠が残る画像は正式公開版にしない。
4. 看板、時刻、荷札、効果音など、世界内の情報として必要な文字だけ画像へ直接残す。
5. 旧画像に既に入っている台詞や説明枠は、新脚本と一致していても再組版し、文字品質を統一する。
6. 画像内台詞版はWeb公開版を上書きせず、SNS展開のSTEPで別書き出しにする。
7. M・N判定の作業が終わるまで、旧画像を削除しない。
