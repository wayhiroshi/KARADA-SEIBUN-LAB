# SNS投稿・記事 公開前チェックリスト

最終更新: 2026-08-15

> 内部運用専用。読者向けの投稿、プロフィール、記事本文には転載しない。公開が必要な表示だけを、対象の販売投稿へ掲示する。

## 公開境界（1項目でも不合格なら公開しない）

- [ ] 法令・規約・科学的正確さは内部で確認し、読者向け本文を予防線や否定の列挙にしていない
- [ ] 法令上または誤認防止上必要な表示だけを、短く自然な位置へ置いている
- [ ] 描画指示、制作意図、確認手順、表示指定、禁止事項、コマID、制作ステータス、SEO・運用メモが公開HTML、alt、aria-label、構造化データにない
- [ ] 漫画は解説を読ませてからではなく、タイトルの次に物語が始まる
- [ ] 人物紹介は、初見でも性格と役割が浮かぶ短く自然な日本語になっている
- [ ] 雑誌編集者の目線で音読し、読みやすく、分かりやすく、楽しい内容に仕上げた

## 0. 読みやすさと一記事一トピック

- [ ] この記事で答える読者の疑問を、一文で書ける
- [ ] 読後に分かることを、一文で書ける
- [ ] 一記事に中心トピックが一つだけである
- [ ] 別の専門用語、別工程、応用、例外を次回記事へ分けた
- [ ] 読者が既に知っていることから、一段だけ先へ進んでいる
- [ ] 主図解だけを見ても中心的な関係が分かる
- [ ] 長文を画像へ貼り込んでいない
- [ ] 文字だけが長く続く区間や、情報を詰め込んだ画面がない
- [ ] CSS装飾が視線誘導、意味の区別、内容の整理に役立っている
- [ ] 不要な色、枠、影、飾りを省いている
- [ ] スマートフォン幅で余白、行長、画像の見切れ、横スクロールを確認した

## 0-A. 完成前の編集確認

- [ ] 新規記事・全面改稿に `styleVersion: karada-article-v1` がある
- [ ] タイトルが、読者の自然な疑問一つになっている
- [ ] 導入が「身近な発見・最初の理解 → 疑問 → この記事で確かめること」の順になっている
- [ ] 主画像が標準の横長構成で、細かな説明を詰め込んでいない
- [ ] 主画像の直後に、導入を繰り返さない「植井寛の学びメモ」がある
- [ ] 「この記事の要点」が三項目で、本文と同じ順番になっている
- [ ] 本文が一見出し二段落を標準とし、第一段落に答え、第二段落に理由・例・根拠を置いている
- [ ] 本文の一人称を必要最小限にし、筆者の体験を導入と学びメモへ整理している
- [ ] 「です・ます」、短い文、具体的な主語、日常語で統一している
- [ ] 締めが注意や予告ではなく、導入の疑問への答えになっている
- [ ] 規制対応のための否定、留保、予防線が本文に並んでいない
- [ ] 法令・規約上必要な掲示と、内部だけで確認する事項を分けた
- [ ] 記事の中心が「言えないこと」ではなく「読者に分かること」になっている
- [ ] 制作意図、更新手順、SEO、管理方法など、運営側への説明を一般読者向けの文章へ混ぜていない
- [ ] 公開文は運営者の作業ではなく、読者が得られる理解や読み方を伝えている
- [ ] 雑誌編集者の目線で、タイトルから末尾まで初見として読み直した
- [ ] 一度読めば意味が通り、主語・目的語・指示語が曖昧でない
- [ ] 段落のつながりが自然で、唐突な話題転換や不要な断りがない
- [ ] 音読しても不自然でない日本語になっている
- [ ] 筆者の疑問、調査、理解の順序と、著者メモの目線が一致している
- [ ] 見出し、本文、図解、SNS原稿の語調と結論がそろっている
- [ ] 最後が注意書きではなく、その記事で分かったことを自然に結んでいる

## 0-B. イラストの目視確認

- [ ] 人物の目線が、本、資料、相手、対象物など見るべき先へ向いている
- [ ] 顔、首、手、腕、体の向きが自然である
- [ ] 持っている物、指し示す先、机上の物の関係が成立している
- [ ] 筆者として描いた人物が、登録済みの筆者像と一致している
- [ ] 筆者役、読者役、研究者役が混同されていない
- [ ] 人物同士に不要な接触や過度な親密さがない
- [ ] 本文にない効果、感情、因果関係をイラストが暗示していない
- [ ] Web用画像とSNS用画像を、書き出し後の実物で確認した

## 1. 投稿種別を決める

- [ ] 一般情報、研究解説、販売PR、利用記録のどれか一つに分類した
- [ ] 一般情報・研究解説と販売PRを同じ投稿で混ぜていない
- [ ] 製品販売へつながる投稿は、本文・画像・動画・プロフィール・リンクを含めて広告として審査する

## 2. 一般情報・研究解説

- [ ] 核酸一般の説明を特定製品の効果へ置き換えていない
- [ ] 細胞、動物、人の研究を区別した
- [ ] 対象者数、期間、比較対象、主要評価項目、限界を確認した
- [ ] 資金提供・利益相反を確認した
- [ ] 論文タイトルや結論だけを誇張していない
- [ ] 原典URLと確認日を制作メモへ残した
- [ ] 診断、治療、予防、身体機能改善、若返りを食品の効果として断定していない

## 3. 販売PR投稿

- [ ] 投稿冒頭または見落とされない位置に「PR」または「広告」がある
- [ ] フォーデイズ会員であり、購入で販売ボーナス等が反映される関係を明示した
- [ ] 公式ショッピングモールロゴを公式指定どおり掲載した
- [ ] 個人用招待URL・QRを加工していない
- [ ] 掲載媒体・配置がFordaysの書面回答で許可されている
- [ ] 購入者は会員登録不要で通常価格購入することを正確に説明した
- [ ] 販売・配送主体がフォーデイズ社であることを誤認させない
- [ ] 「MLMではない」「アフィリエイトだから無関係」などの不正確な表現がない

## 4. 製品表示

- [ ] 公開日に公式商品ページとショッピングモールで価格・在庫を確認した
- [ ] 商品名、名称、内容量、原材料、目安量、注意事項が最新である
- [ ] 「DNA含有原料」と「DNA量」など、異なる数字を混同していない
- [ ] 1本、100ml、1日目安量など数字の基準を明示した
- [ ] 体験談を効果保証として使っていない
- [ ] 服薬・アレルギー等の公式注意事項を省略して誤認させていない

## 5. 公式画像・ロゴ

- [ ] 会員サイトから取得した最新の公式素材である
- [ ] 製品画像を第三者から受け取ったり、第三者へ渡したりしていない
- [ ] 縦横比を保った拡大・縮小以外をしていない
- [ ] トリミングしていない
- [ ] 文字、イラスト、装飾を重ねていない
- [ ] 色調補正、背景除去、合成をしていない
- [ ] カタログPDFから画像を切り出していない
- [ ] プラットフォームの自動トリミングが起きない表示形式を実機で確認した

## 6. 公開画面

- [ ] iPhone相当の幅でPR表示・ロゴ・本文が欠けていない
- [ ] 招待コードが削除されず公式ショッピングモールへ遷移する
- [ ] 短縮URL、リダイレクト、解析パラメータを使っていない
- [ ] 誤った会員IDになっていない
- [ ] リンク先の商品・価格・購入条件と投稿が一致する
- [ ] 公開日時、確認者、根拠資料の版を制作記録へ残した

## 7. 公開後

- [ ] コメントやDMで個別の病気・服薬相談へ回答していない
- [ ] 購入者個人を特定・照合しようとしていない
- [ ] 誤りが判明した場合は投稿を訂正または停止した
- [ ] 規約・価格・商品表示の変更を月1回確認した
