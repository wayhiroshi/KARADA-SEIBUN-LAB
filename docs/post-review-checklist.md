# SNS投稿・記事 公開前チェックリスト

最終更新: 2026-07-27

## 1. 投稿種別を決める

- [ ] 一般情報、研究解説、販売PR、利用記録のどれか一つに分類した
- [ ] 一般情報・研究解説と販売PRを同じ投稿で混ぜていない
- [ ] 製品販売へつながる投稿は、本文・画像・動画・プロフィール・リンクを含めて広告として審査する

## 2. 一般情報・研究解説

- [ ] 核酸一般の説明を特定製品の効果へ置き換えていない
- [ ] 細胞、動物、人の研究を区別した
- [ ] 対象者数、期間、比較対象、主要評価項目、限界を確認した
- [ ] 資金提供・利益相反を確認した
- [ ] 論文タイトルや結論だけを誇張していない
- [ ] 原典URLと確認日を制作メモへ残した
- [ ] 診断、治療、予防、身体機能改善、若返りを食品の効果として断定していない

## 3. 販売PR投稿

- [ ] 投稿冒頭または見落とされない位置に「PR」または「広告」がある
- [ ] フォーデイズ会員であり、購入で販売ボーナス等が反映される関係を明示した
- [ ] 公式ショッピングモールロゴを公式指定どおり掲載した
- [ ] 個人用招待URL・QRを加工していない
- [ ] 掲載媒体・配置がFordaysの書面回答で許可されている
- [ ] 購入者は会員登録不要で通常価格購入することを正確に説明した
- [ ] 販売・配送主体がフォーデイズ社であることを誤認させない
- [ ] 「MLMではない」「アフィリエイトだから無関係」などの不正確な表現がない

## 4. 製品表示

- [ ] 公開日に公式商品ページとショッピングモールで価格・在庫を確認した
- [ ] 商品名、名称、内容量、原材料、目安量、注意事項が最新である
- [ ] 「DNA含有原料」と「DNA量」など、異なる数字を混同していない
- [ ] 1本、100ml、1日目安量など数字の基準を明示した
- [ ] 体験談を効果保証として使っていない
- [ ] 服薬・アレルギー等の公式注意事項を省略して誤認させていない

## 5. 公式画像・ロゴ

- [ ] 会員サイトから取得した最新の公式素材である
- [ ] 製品画像を第三者から受け取ったり、第三者へ渡したりしていない
- [ ] 縦横比を保った拡大・縮小以外をしていない
- [ ] トリミングしていない
- [ ] 文字、イラスト、装飾を重ねていない
- [ ] 色調補正、背景除去、合成をしていない
- [ ] カタログPDFから画像を切り出していない
- [ ] プラットフォームの自動トリミングが起きない表示形式を実機で確認した

## 6. 公開画面

- [ ] iPhone相当の幅でPR表示・ロゴ・本文が欠けていない
- [ ] 招待コードが削除されず公式ショッピングモールへ遷移する
- [ ] 短縮URL、リダイレクト、解析パラメータを使っていない
- [ ] 誤った会員IDになっていない
- [ ] リンク先の商品・価格・購入条件と投稿が一致する
- [ ] 公開日時、確認者、根拠資料の版を制作記録へ残した

## 7. 公開後

- [ ] コメントやDMで個別の病気・服薬相談へ回答していない
- [ ] 購入者個人を特定・照合しようとしていない
- [ ] 誤りが判明した場合は投稿を訂正または停止した
- [ ] 規約・価格・商品表示の変更を月1回確認した
