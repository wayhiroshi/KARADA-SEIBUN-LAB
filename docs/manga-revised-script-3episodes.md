# 漫画『からだ成分ラボ』3話構成・改訂脚本

最終更新: 2026-08-16
状態: Web公開版（全3話・65コマ、一次資料照合済み）

## 台詞の確定状態

- コメディ、人物口調、ナレーションは、Web公開版の編集確定稿とする。
- 科学的な意味を含む語は一次資料と照合した。専門家による医学監修を受けたとは表示しない。
- 成分研究の条件と日常のお茶を同一視せず、研究のたとえであることを各話ページに表示する。
- SNS用など画像単体で配布する版を作る場合だけ、別工程で画像内へ台詞を組版する。

## 1. 改訂の目的

旧版87コマを、スマートフォンで最後まで読みやすい3話構成へ再編集する。

- 第1話は「食後、体内物流が混雑する様子」に絞る。
- 第2話は「食事前に準備しておくと、物語上の物流がどう変わるか」に絞る。
- 第3話は「二個目のケーキを、自分の感覚で明日に残す判断」に絞る。
- 工場、配送、倉庫は、体の仕組みを分かりやすくするために単純化した比喩として扱う。
- お茶を飲めば脂肪への保管がゼロになる、食欲が消える、必ず食べる量が減る、とは描かない。
- 11時45分から12時までの15分は主人公の生活上の習慣として描く。効果が最大になる保証条件として説明しない。
- 成分キャラクターの作業は視覚的な比喩とし、個別成分の機序を台詞で断定しない。
- 商品名、企業名、商品パッケージ、ロゴはコマ内に出さない。
- 公開ページ側では「体内の描写は、理解しやすくするために単純化したイメージです」と明示する。

## 2. 共通作画仕様

- 全コマ正方形、1:1。スマートフォンの縦スクロールを前提とする。
- Web公開版は、画像と読み上げ可能なHTML台詞を分ける。画像内に空の吹き出しを置かない。
- SNS用画像では、必要な台詞だけを画像内へ組版し、Web版の画像を上書きしない。
- 画像生成時に必要な空白は確保するが、画面の20%以上を用途未定の白い空間にしない。
- 現実世界は柔らかな昼光、木目、クリーム色を中心にする。
- 体内世界は、既存の明るい食品加工工場風の背景へ統一する。
- 配送員は「インスリンそのもの」ではなく、「インスリンなどの合図を受けて動く体内配送チーム」という物語上の設定に変更する。
- 「脂肪倉庫」は「エネルギー保管倉庫（通称・脂肪倉庫）」とし、脂肪を悪役にしない。
- 既存画像を使う場合も、看板、荷札、吹き出し、埋め込み文字は新脚本に合わせて修正する。

# 第3話　二個目のケーキ、どうする？

## この話で答える疑問

この記事では「目の前にもう一個あるとき、我慢ではなく自分の満足感で決めるとはどういうことか？」に答える。

## 読後の結論

甘味を感じることと、もう一個食べると決めることは同じではなく、最後に選ぶのは本人である。

## 話数仕様

- 全15コマ。
- ギムネマは主人公を操作する役ではなく、甘味信号を「追加要求」と取り違えない受付担当として描く。
- 一個目を食べた事実は消さない。
- 主人公の満足感を、ギムネマの操作より先に現実世界で描く。
- 「二個目ぶんの追加便が来ない」とだけ表現し、脂肪倉庫への余剰便がゼロになるとは描かない。

4. 「糖質原料」「エネルギー便」「保管ルート」は単純化した物語上の比喩と明示する。
5. 商品、飲用方法、痩身、摂取量減少の効果保証へつながる表現を置かない。

# 6. 制作順序

1. この脚本の台詞と健康表現を確定する。
2. 旧87コマを「再利用」「文字修正」「再生成」「削除」に分類する。
3. 第1話だけを先に作画・組版し、スマートフォン幅で試読する。
4. 読者が物流の比喩を理解できるか確認してから、第2話を制作する。
5. 第3話は、甘味信号と本人の判断が混同されていないことを試読で確認する。
6. SNS用の画像内台詞版が必要になった時だけ別ファイルとして書き出す。
